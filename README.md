A complete interpreter for make.fun's tiny stack ISA: 32-bit wrapping ints, 256-value stack, calls, 256 words of memory, byte I/O, and all ten traps with their own exit codes. `main.ts` answers all 40 instances in one run. Practice set: 40/40 instances correct, score 1,000,000, both runs byte-identical.
